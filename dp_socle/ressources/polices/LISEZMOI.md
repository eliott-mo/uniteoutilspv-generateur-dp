# Polices embarquées

Déposez ici `Aptos.ttf` (et `Aptos-Bold.ttf` si vous l'avez).

Aptos est une police Microsoft, distribuée avec Microsoft 365. Elle n'est pas
redistribuable librement : le fichier n'est donc pas versionné ici, il doit être
copié à la main depuis un poste où Microsoft 365 est installé.

Sans ce fichier, `dp_socle.polices` émet un avertissement explicite au démarrage
et les planches sont composées avec la chaîne de repli déclarée
(`Carlito, Calibri, DejaVu Sans, sans-serif`), dont les métriques diffèrent.
